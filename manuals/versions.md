这里记录手册说明的是哪份程序。核对版本并不意味着它就是 npm 上的最新版；若界面或类型不同，先检查你实际安装的版本。

| 手册 | 本轮本地基线 | 核对范围 |
| --- | --- | --- |
| ZPI | Desktop 0.3.35；Git `59be3dcb018e5e0c9bb55c3045fbc2ff44e4b578` | 启动器、设置和面板、工具装配、会话宿主及对应测试 |
| ZPI Quick Chat | 0.1.14；Git `aa5f344c4305428eb6c0b9c0b44977739368d7e4` | CLI、macOS 捕获与焦点、输入、窗口、对话；锁文件与安装包均指向 SDK 0.1.63 |
| ZPI Agent SDK | 0.1.65；与 Desktop 相同 Git 版本 | package.json 的两个公开入口、声明文件、运行时校验、会话与宿主测试 |

**读者看到的三种环境。** 官网的桌面、文件和搜索结果是页面内的预设，SDK 一秒后显示固定问候，不连接你的账号。安装后的桌面与 Quick Chat 会访问配置的模型，工具在本机运行。SDK 在你的 Node 进程中运行；能否收费、有哪些模型取决于你的服务商和权限。

**本轮验证不包括**真实订阅授权、付费模型回复、系统级全局按键注册、跨应用选区或桌面截图授权。在手册中，这些步骤描述的是应当观察的结果，不是已在你的设备上完成的动作。

旧资料曾建议在工作区运行 `npm run docs`，该脚本不在本轮工作区的 package.json 中。历史协作指南所写的「默认」提示预设现为 Codex。归档后的 OpenAI 内置目录已更新（含 GPT-6.2 系列），ChatGPT 订阅对服务端明确标为过载的错误也有单独的有限重试策略。不要把历史模型截图当作账号资格，或把过载处理套用到所有错误。Quick Chat 的网页工具在自己的程序里装配，不能因此推断桌面插件的设置也会传过去。
