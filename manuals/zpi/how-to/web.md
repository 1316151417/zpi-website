# 让新任务查一份公开资料，并核对出处

模型回答「据官网介绍」不代表它刚刚查过官网。你需要明确启用联网服务，并能从实际工具记录找到根据。

1. 在 **设置 → 联网搜索**，确认上方「启用联网搜索」已开。这是插件开关；只打开它还没有可用服务。
2. 在同页 **DeepSeek** 提供商中填入你有权使用的搜索 API Key，保存并启用该提供商。聊天模型不必改成 DeepSeek。若显示已保存的凭据尚未解锁，先解锁系统密钥存储再重开应用，不要反复覆盖已有 Key。
3. 新开任务，首次发送：「请搜索 Node.js 官网的发布说明，打开找到的公开页面，列出标题、链接和说明中的一项变化。」真实请求会把查询或 URL 发给网页服务，可能计费；不要填入私网地址、私有材料或带令牌的 URL。
4. 展开 `web_search` 查看实际结果，再看 `web_fetch` 是否真的读到对应页面。打开来源交叉核对原文中的标题和变化；只见普通回答、没有工具结果时，就还没有验证出处。抓取失败时可换可公开访问的正文链接，不能把被拒绝的地址算作已查阅。

以后不需要时停用提供商；保留 Key 与移除凭据是不同操作。新对话的插件清单与实时服务状态如何共同决定工具，见[启用条件](../reference/tools.md)。
