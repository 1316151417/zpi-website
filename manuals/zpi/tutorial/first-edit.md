# 第一次用 ZPI：只改练习目录里的一行

想知道它是真的动了文件，还是只在聊天里给了建议？这次只把一项待办的「未开始」改成「已完成」。最后你会同时看到磁盘上的新内容和 ZPI 记录的差异。

## 准备一张可以丢掉的练习纸

需要符合[运行环境](../reference/setup.md)的电脑、终端，以及你有权使用的模型账号或 API Key。模型请求需要网络，可能消耗额度。不要选真实项目，也不要在练习目录里放凭据。

在 macOS 终端执行以下命令。`mktemp` 每次创建不同的新目录，不会覆盖上次的练习：

```sh
practice=$(mktemp -d "${TMPDIR:-/tmp}/zpi-practice.XXXXXX")
printf '状态：未开始\n保留：蓝色\n' > "$practice/note.txt"
open "$practice"
```

Finder 打开一个只含 `note.txt` 的目录。保留这个窗口：稍后可把文件夹拖入系统目录选择器，或按 Command+Shift+G 输入终端中 `printf '%s\n' "$practice"` 给出的完整路径。

## 启动并选一个模型

1. 另开一个终端标签运行 `npx @zpi-dev/desktop`，保留刚才准备目录的标签。首次会下载包和 Electron；软件启动后能看到左侧任务列表和中间输入框。
2. 点左下角 **设置 → 模型**。例如选 DeepSeek 预置，配置自己的 Key 并保存，启用要用的模型；已经通过环境变量配置好的提供商无需重复添加。也可以[使用 ChatGPT 账号](../how-to/models.md)。
3. 返回工作区，点输入框的模型选择器。能选到模型是这一步的检查点；没有模型时先不要发出任务。

## 让它做一次可核验的编辑

1. 在左侧 **项目 → 添加项目** 选择刚才 Finder 打开的目录。在该项目旁新建任务，确认不是全局的无项目草稿。保留本地目录，不选新工作树。
2. 输入：「先读 `note.txt`，只把第一行改成 `状态：已完成`。第二行保持不变，不创建其他文件。」按 **Enter**。原版默认不显示发送按钮，不必寻找它。
3. 等一次回复结束。展开执行经过，找读取和编辑（或写入）记录。若它只解释了做法，指出「请实际修改该文件」，不要把回答里的示例当作磁盘结果。
4. 点回复下的文件改动，或打开右侧 **审查 → 上一轮更改**；找到 `note.txt`，应只有第一行从旧值变到新值。从 Finder 再次打开 `note.txt`，或回到原终端运行 `cat "$practice/note.txt"`：第一行应为 `状态：已完成`，第二行仍是 `保留：蓝色`。磁盘内容和差异一致就完成了；不需要 Git 仓库。

没看到文件？先确认任务所属目录。模型报错？检查提供商、模型是否启用以及账号额度。不要改用有真实数据的目录来「试试看」。下次可跳过教程，直接用[如何查看刚才改了什么](../how-to/review.md)。
