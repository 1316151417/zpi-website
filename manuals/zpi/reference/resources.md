# 设置、资源文件与生效范围

要查「为什么保存后旧任务没变」，先区分本机界面偏好、首次发送的快照，以及输入框的实时资源候选。

| 设置分类 | 配置内容 | 范围或默认 |
| --- | --- | --- |
| 常规、界面设置 | 本机行为、主题、界面字号、代码预览等 | 原版默认系统主题、14px，发送按钮隐藏；官网的浅色起始值不代表新装应用 |
| 快捷键 | 总开关、绑定及冲突 | 保存后生效；见[键位表](shortcuts.md) |
| 系统提示词、工具 | 查看基础提示、附加指令、工具声明 | 查看并不是编辑；能力变更去相应插件/服务 |
| 技能 | 用户 `~/.agents/skills/`、`~/.zpi/skills/` 与项目同名相对目录；每个技能目录含 `SKILL.md` | frontmatter 与描述必须可读。`$` 或斜杠菜单选用，选中不自动发送；显式调用再读正文 |
| 命令 | 个人/项目提示模板、描述、参数提示、启停与导入 | `/名称` 调用；`$ARGUMENTS` 为整体参数，`$1` 等为位置参数。链接导入与独立副本区别在后续编辑是否会影响源文件 |
| 模型、联网搜索 | 模型目录与账号；专用联网凭据 | 两类配置独立；见[工具条件](tools.md) |
| 插件、子智能体 | 内置或显式导入的本地插件；个人/项目 Agent 定义；模型、工具和提示策略 | 新任务首次发送冻结插件。当前子智能体定义/启停影响新启动，不追溯已启动的子会话 |
| 钩子 | 用户或项目级进程/命令，事件、匹配条件、参数、超时和启停 | 新会话生效；插件贡献的只读钩子跟随插件。桌面可配置事件包括 SessionStart、UserPromptSubmit、PreToolUse、PostToolUse、PostToolUseFailure、Stop、InputAccepted、RunStart、RunEnd、Notification |
| 记忆 | 关闭、短期（默认）或长期；用户和项目范围 | 短期文件分别为 `~/.zpi/MEMORY.md` 与绑定项目的 `.zpi/MEMORY.md`。每份最多 20 项、正文共 2000 个 Unicode 码点；稳定唯一 `- [id] 正文`，非法文件不自动注入 |
| 已归档任务 | 恢复、永久删除、自动归档 | 规则及跳过条件见[归档指南](../how-to/search-archive.md) |

技能目录信息、注入指令与记忆快照不是持续观察每个文件。当前输入候选可以更新，已经进入对话的内容不会因此消失。长期记忆的提取/整合可能调用模型；默认模型跟随，满足空闲、年龄等条件才处理。「检查」不保证立即生成新结论。

不要把第三方 Shell 命令、插件或 Hook 当作纯文本主题：它们可以用本机权限执行。第一次只需要复用一段文字，选[创建提示命令](../how-to/customize.md)即可。
