# 内置工具、共享任务工具与启用条件

这里查**桌面主任务**能看见哪些工具。名称区分大小写；此表不是 SDK 的工具菜单，也不是「装了插件就必定可调用」的承诺。

| 来源 | 名称 | 参数/作用与边界 |
| --- | --- | --- |
| 基础 | `read` | `path`，可选 `offset`、`limit`；读文本或支持的图片，大文件分段 |
| 基础 | `bash` | `command`；运行本机 Shell，不受 cwd 的权限隔离 |
| 基础 | `edit` | `path` 和 `edits`；按唯一、互不重叠的 `oldText` → `newText` 精确替换。上下文已变应重新读取 |
| 基础 | `write` | `path`、`content`；创建或覆盖文件，不是追加一段 Diff |
| 向用户提问 | `AskUserQuestion` | 1–4 个问题，每个 2–4 个选项；用户可选、输入文字或点「忽略」不作答。开始交互可暂停自动倒计时；未交互默认五分钟后按无答案继续，停止运行会取消所属等待 |
| 子智能体协作 | `Agent`、`SendMessage` | 派生独立子任务、按已返回的子智能体 ID 发消息。定义、模型和可用工具取决于设置；已有子会话不自动变成新定义 |
| 后台命令 | 覆盖现有 `bash`，**不是第 12 个工具** | 该版本支持 `description`、`run_in_background`、以毫秒计的 `timeout`（默认 120000，上限 600000）；可转后台的前台命令超时转后台，普通 sleep 等待例外。不要把毫秒约定套在未装配插件的基础工具上 |
| 子智能体协作 **或** 后台命令 | `TaskOutput`、`TaskStop` | 使用返回的 `task_id`，按会话校验归属；任一后端开启就贡献这同一对工具。输出查询默认可等待，正常完成会通知，勿反复轮询 |
| 联网搜索 | `web_search`、`web_fetch` | 搜索 query / 读取已知公网 HTTP(S) URL；插件启用 **且** DeepSeek 联网提供商已配置有效专用 Key、启用后才装配 |

**如何计数：** 基础 4 + 提问 1 + 协作 2 + 共享 2 + 联网 2 = 内置主任务最多 11 个。新安装的内置插件开关默认开启，联网服务默认未启用，所以没有联网凭据时通常是 9，不是 11。记忆、标题或通知可以贡献指令和生命周期行为，而不增加这张表的名称数。

**在哪里核对：**「设置 → 工具」查工具说明与参数；「插件」查启用来源；「联网搜索」配置服务。新任务**首次发送**冻结装配；改开关不能给旧任务临时追加工具。停用服务或移除 Key 会影响后续实际联网请求。协作提示预设当前默认 Codex，不代表可以越过父任务给定的边界。

要实际验证网页来源，按[给新任务接上联网](../how-to/web.md)操作；遇到正在运行的 ID，按[查看/停止后台任务](../how-to/background.md)操作。
