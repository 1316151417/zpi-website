# start | 第一次叫出浮窗
## purpose | 什么时候用 Quick Chat？
看邮件时遇到一句难懂的英文，不必切换到项目工作区。Quick Chat 在当前应用上方放一个输入条；发出消息才展开对话，读完可以收起。它没有 Desktop 的项目列表、插件市场或归档入口。

只要问一句，直接打字就行。联网和本机工具默认都关闭，读取选区与截屏也不是启动条件。先[启动浮窗](install.html)，需要材料时再了解对应的系统权限。
## install | 在 Mac 上配置 DeepSeek 并启动
需要 Apple Silicon Mac、Node.js 24 和自己的 DeepSeek API Key。在 Mac 自带 zsh 终端运行下面三行。提示出现时粘贴密钥，按回车；输入不回显，也不用把真实 key 写进命令历史。

```zsh
read -rs 'DEEPSEEK_API_KEY?DeepSeek API Key: '; echo
export DEEPSEEK_API_KEY
npx @zpi-dev/quick-chat
```

保持这个终端开着，按 **Option+Space**。看到输入条即为启动成功。Quick Chat 不读取 Desktop 的 ChatGPT 登录或模型设置；普通打字无需申请屏幕录制权限。真实消息可能产生模型费用。
## translate | 第一次提问：翻译眼前的一句话
在文本编辑器输入并选中 `Small tools can make a big difference.`。按 **Option+Shift+C**。看到文字出现在浮窗里时，它只是草稿，**尚未发送**。如果尚未授权复制选区，可先手动复制，再按 Option+Shift+V。

<figure class="interface-shot"><img src="../../media/quick-draft.webp" width="360" height="64" alt="小输入条里只有英文原文，右侧发送箭头仍可点击，没有任何已发出的消息"><figcaption>看见这条草稿时仍可修改；带入不是发送。</figcaption></figure>

在这句话旁加上「翻译成自然中文」，按 Enter。输入条展开后应看到自己的消息和中文回答。不要求译文逐字相同。按 Option+Space 收起，回到原文稿；再次叫出，仍可沿这次翻译追问。

# capture | 把眼前的内容带进来
## selection | 直接带入选中的文字
保持原应用在前台，先选一小段文字，再按 **Option+Shift+C**。Quick Chat 会先尝试复制原选区，再打开浮窗。核对草稿中的文本，添加问题后才按 Enter。

这条路线需要辅助功能许可来触发复制；某些应用本身不支持复制。先在普通文本编辑器试，或改用[剪贴板带入](clipboard.html)。不用为了带入选区就先点开浮窗，否则焦点已经变了。
## clipboard | 带入已复制的文字或图片
在原应用复制内容，按 **Option+Shift+V**。回到草稿确认出现文字或图片缩略图。已有草稿时核对追加位置，删掉不打算发送的旧内容，再补问题。

如果出现上一次复制的材料，先手动粘到文本编辑器验证剪贴板。这个快捷键读取现成剪贴板，不会替你重新复制眼前的选区。
## screenshot | 只截需要解释的区域
按 **Option+Shift+A**。浮窗先让开，拖选屏幕上需要说明的一块，例如对话框里的错误信息；取消区域选择不会提交新问题。

截图回到草稿后点开核对内容，把账号或私人信息排除在外，再写「这条提示在说什么？」并发送。只有这条路线才需要检查 macOS 屏幕录制授权；普通翻译不用开它。
## images | 发送前检查或移除图片
看到缩略图后点击预览，确认不是整张桌面或上一张图。用移除图片按钮删掉不需要的附件，保留目标图片后说明想检查的区域。

支持 PNG、JPEG、WebP、GIF。过大或格式不支持时，用本机工具裁切或导出一份较小副本，别通过反复按发送来重试同一份无效图片。

# replies | 阅读与追问
## follow | 接着问，不要把材料再贴一遍
第一条回答结束后，在同一个浮窗输入「刚才第二个词还能怎样译？」。应在原消息下方追加新一轮。生成还未结束时先等待或停止，不要用新对话按钮催促它。

Shift+Enter 在草稿里换行，Enter 发送。需要全新上下文才新建对话；隐藏窗口不清掉上一轮。
## copy | 把回答或代码带回原应用
读回答时可向上滚动查看前文，不必跟着每个新字移动。要整条回答选消息的复制操作；只要代码就用代码块复制，粘到目标编辑器核对换行。

不想因切应用而看不见答案时先固定浮窗。复制的文字由你决定保存在哪里，Quick Chat 不会为你建立持久的历史库。
## tools | 查看工具经过，不把猜测当结果
回答声称查了网页或执行了命令时，展开对应的工具记录。核对查询词、文件路径或命令，看状态是完成、已停止还是未完成，并读实际输出。

无工具的普通翻译不会出现工具记录。回答提到一个网址不代表它真的搜索过；需要当期资料时在新对话中启用联网。

# window | 浮窗与会话
## pin | 固定浮窗，边看答案边工作
发送消息让输入条展开后，点右上角图钉，再点回原应用。浮窗应继续留在眼前。再次点击取消固定，恢复失焦隐藏；紧凑输入条没有这个按钮。

固定只影响失焦行为。即使已固定，仍可按 Option+Space 主动隐藏，不必结束当前回答。
## move | 移动浮窗或改变大小
在窗口可拖动的空白区域按住移动。展开后可拖动边缘和角改变大小；输入条则会随多行文本或图片向上扩展，不要拖正文来移动窗口。

收起再打开应保持本次运行里调整过的位置或大小；几何尺寸受屏幕可用范围限制。这不是保存一份桌面工作区布局。
## hide | 收起窗口，回来继续
用 **Option+Space** 隐藏或显示。没固定时点回原应用也会隐藏。下次打开应看到当前会话；已有草稿没有因为显隐被当作消息提交。

隐藏不是停止。如果你不希望生成继续进行，先用停止操作，再隐藏。
## stop | 只停止当前回答
正在生成时点停止或按 Esc，核对这条回答显示已停止。已显示的文字保留，可据此重新提问。若前面有图片预览或来源弹层，先关闭局部视图。

空闲时 Esc 用来隐藏，所以不要连续盲按两次。停止不会撤销本机命令此前已经完成的动作。
## reset | 新建对话会清掉什么？
按 **Option+Shift+Space**，或点击新对话按钮。先把重要内容复制到自己的文档；新对话会清除当前历史和草稿，重置两个工具开关和固定状态。

检查新输入区为空。展开状态的可见窗口不一定立即缩成输入条；判断是否已新建，要看消息与草稿，不只看窗口大小。
## quit | 完全退出，而不仅是隐藏
回到启动 Quick Chat 的终端按 Ctrl+C，等程序结束。按全局唤起键不应再由这次运行响应。需要时在有相同环境变量的终端重新启动。

会话只在内存里，不会同步到 Desktop；退出后不能靠重启找回答案。不要用退出作为临时收起的替代。

# capabilities | 只在需要时使用工具
## web | 查当前资料：启用联网搜索
在**空对话、首次发送之前**打开地球按钮。问一个有时效且可核对的问题，例如「查 Node.js 官方发布时间表，给出来源」。展开搜索查看查询词和网页结果；必要时让它读取某个公开页面。

工具选择在本会话第一次发送后锁定。想从纯聊天改成联网，先保存必要内容，再新建对话。私人地址、登录后页面或带凭据的 URL 不适合此工具。
## sources | 打开网页来源验证回答
有联网结果时，点回答的 **来源**，从列表核对域名和页面标题，打开原页面找到支持结论的段落。问发布时间时同时核对具体版本与日期。

“有来源”不等于“来源支持每一句话”。若结论对不上，追问哪一段是引文，哪一段是推断；不要只让它重复同一句回答。
## local | 让 Quick Chat 读取本机材料
首次发送前打开本机工具按钮，查看提示中的工作目录。默认起点是用户主目录，不是 Desktop 当前项目。用一个无敏感内容的练习文件，给出明确路径，要求只读第一行。

本机工具包括 Read 和 Bash，**不只是文件搜索**。命令能在当前用户权限下产生真实修改；不需要本机数据时保持关闭。启用两种工具会同时增加本机访问和外部传输的可能。
## privacy | 哪些内容可能离开电脑？
采集完成先进入草稿；主动发送时，文字和所附图片可能交给模型服务。开启搜索后查询词和指定网页也会交给联网服务；本机工具返回的内容可能进入后续模型请求。

练习时只选一句话或一个小区域，删掉不需要的附件。会话不在本地持久保存，不等于外部服务不处理请求，也不能撤回已经发送的数据。

# help | 快捷键与排错
## keys | Mac 快捷键速查
| 想做什么 | 默认键 |
|---|---|
| 唤起或隐藏 | Option+Space |
| 清空并新建对话 | Option+Shift+Space |
| 带入选区 / 剪贴板 / 区域截图 | Option+Shift+C / V / A（均带 Option+Shift） |
| 发送 / 换行 | Enter / Shift+Enter |
| 停止生成；空闲时隐藏 | Esc |

只有前三行是全局入口；发送和停止要在合适的窗口状态下操作。
## hotkey | 按快捷键没有浮窗
先看启动终端是否还在运行，有没有“无法注册快捷键”及具体组合。关闭或重配占用该组合的程序，再启动一次；不要同时运行多个实例试抢同一个快捷键。

若 Option+Space 可以唤起而选区带入不行，说明不是所有快捷键都失效。分开检查原应用是否允许复制，以及系统权限。
## permission | 区分辅助功能与屏幕录制权限
自动复制选区失败，到「系统设置 → 隐私与安全性 → 辅助功能」检查对应运行应用；区域截图失败才去查屏幕录制。按系统提示重新打开应用后，用不含私人内容的窗口验证。

不愿授予权限时仍可手动输入，也可先手动复制再从剪贴板带入。不要因为模型鉴权错误去扩大系统授权。
## model | 排查密钥错误，调整推理选项
启动终端提示 `DEEPSEEK_API_KEY is required` 时，在**同一个终端**设置变量再运行，不要把 key 当聊天内容发送。当前配置只支持 `ZPI_QUICK_CHAT_MODEL=deepseek`，不能用 Desktop 的提供商名称替代。

要调整推理，在启动前设 `ZPI_QUICK_CHAT_REASONING=low` 或 `disable`，再重启。运行中的错误可点输入区错误标记看原因；认证、网络和图片过大要分别处理。
## limits | 图片、消息和平台限制
本册对应 Quick Chat 0.1.14，要求 Node.js 24 和 macOS arm64。单条文字上限 32,000 个 UTF-16 代码单元；最多 5 张图片，每张不超过 10 MiB 和 16×1024×1024 像素。

单会话还有 200 条消息及 32 MiB 内容限额。快到上限时先复制需要的结论，再新建对话。网页浮窗是模拟演示，不会申请系统采集权限或测试真实密钥。
