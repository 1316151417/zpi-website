# 配好账号，并为下一条消息换模型

模型菜单里没有能用的模型，通常需要先配置提供商，而不是改提示词。下面三条路径各走一条即可。

## 用 API Key 或自定义服务

打开 **设置 → 模型 → 添加模型提供商**。从预置选服务，或在自定义提供商里填实际 API 地址、协议、凭据和模型 ID。保存后确认提供商和对应模型都启用；有目录刷新操作时可以重新获取。不要把网页端登录地址填成 API 地址。协议和环境变量见[安装与接入参考](../reference/setup.md#providers)。

## 用 ChatGPT 订阅

选择 **OpenAI（ChatGPT）→ Continue with ChatGPT**，启动浏览器授权，核对登录账号后返回应用。需要时按界面处理回调地址；不需要复制网页 Cookie。登录完成但目录加载失败时，先重取目录，不要假定所有订阅都能使用菜单中的每个模型。实际可用范围与额度由账号决定。

## 在当前任务切换

返回输入框，点模型选择器，先选提供商和模型，再按模型能力选择思考程度。验证：输入框里出现新名字，发一条很短的消息观察回应。运行中改选不会重写已发出的请求，从下一条消息生效。加速闪电只在受支持的 OpenAI 提供商和模型上出现；会影响用量，不能当作免费开关。

遇到 401，先检查凭据或重新授权；目录能列出但生成失败，还要检查额度、模型 ID 和兼容协议。官方 Responses 连接可复用 WebSocket，不符合条件的兼容网关使用 HTTP；不要把没有复用直接判断为登录失败。持续问题见[定位错误和保护本地数据](data-recovery.md)。
