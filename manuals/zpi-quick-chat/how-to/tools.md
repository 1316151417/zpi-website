# 给一次会话选择联网或本机工具

翻译手头的一段话不需要访问磁盘。先在**空白新会话**的输入框旁选择最少需要的能力；两个按钮默认都关闭。

| 这个问题需要什么 | 第一条消息前怎么选 | 如何核验 |
| --- | --- | --- |
| 只处理带入的材料 | 地球、终端按钮均关闭 | 能回答但没有搜索或文件工具。关闭工具不等于离线模型 |
| 查公开资料 | 只开「联网搜索」 | 可以调用 `web_search`、`web_fetch`。要求核对某条公开说明，完成后点「来源」核对实际取回的网页，不把助手随口给出的网址当成取证 |
| 看本机文本 | 只开「本机工具」 | 可以用 `Read` 和前台 `Bash`。给出一份你允许读取的练习文件的绝对路径；默认 cwd 是用户主目录，不是当前 Finder 目录 |
| 同时比对网页与本机资料 | 两个都开 | 在执行经过分别核对网页与本地工具。只给公开或获准外发的内容 |

首次消息被接受后，工具配置锁定。如果发现少选，先复制需要的上下文，新建对话后重选；运行中不能热加工具。本机工具没有 `Edit`/`Write` 按钮并不等于只读：前台 Shell 拥有当前用户的权限。这里强制关闭 Bash 后台模式，不是桌面端的后台任务管理器。

联网工具使用 Quick Chat 自己的 DeepSeek 配置，不读桌面端的联网插件或专用 Key。私网地址、带凭据的网址不能用作抓取目标；没有成功的工具结果就不该期待「来源」。如只想问另一张图，不用打开本机工具，直接[把图放进草稿](capture.md)。
