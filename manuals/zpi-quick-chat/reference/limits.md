# 输入、图片、消息与工具限制

粘得进输入框不代表组合后的整段对话仍能发送。以下是应用侧校验，不是模型上下文窗口或账单额度。

| 对象 | 限制或默认 | 超出后怎样处理 |
| --- | --- | --- |
| 单条文字 | 32,000 个 JavaScript UTF-16 单元；部分 emoji 占两个单元 | 缩短选区；捕获文字和原草稿合计也受限 |
| 图片 | 每次最多 5 张；PNG、JPEG、WebP、GIF；每张最多 10 MiB；解码面积最多 16 × 1024 × 1024 像素 | 减少张数、缩小分辨率或转支持格式；只改扩展名无效 |
| 空消息 | 至少有非空白文字或一张有效图片 | 图片可与文字一起发送；能否理解图片是模型侧能力 |
| 单次临时对话 | 200 条消息（一次提交通常增加用户与助手两条），32 MiB 内容 | 发前统计文本、图片编码、已有工具输入/输出等，不等于原文件字节和。复制有用结果后新建 |
| 本机工具 | `Read`、`Bash`；cwd 为主目录，Shell 强制前台；未指定超时时给 60,000 ms | 停止可中断本轮，但不能撤销停止之前已经发生的磁盘操作 |
| 联网工具 | `web_search` 查询 1–128 个 Unicode 字符，count 默认 10、范围 1–50；`web_fetch` 仅公网 HTTP(S) | 总时限 30 秒、响应体上限 2 MiB；缩小查询，不要传私有网址或账号令牌 |

浮窗没消失、但不能继续发？若提示会话已结束，应[新建而非只隐藏](../how-to/window.md)。
