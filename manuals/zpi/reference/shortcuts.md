# 桌面默认快捷键速查

这里查新配置中的按键、作用域，以及为什么同一个 Esc 有时只关闭菜单。表中 **主键** 是 macOS 的 Command，其他受支持平台的 Ctrl。

| 按键 | 动作 | 范围 |
| --- | --- | --- |
| macOS `Control+Command+E`；其他 `Ctrl+Alt+E` | 显示/隐藏主窗口 | 全局注册；冲突会报错，不停止运行 |
| `主键+[` / `主键+]` | 开关左侧栏 / 右侧面板 | 应用 |
| `主键+Shift+F` | 进入/退出完整视图 | 应用 |
| `主键+I` | 聚焦任务输入框 | 应用 |
| `主键+N` | 新任务，或复用合适的草稿 | 应用 |
| `主键+K` / `主键+F` | 搜索任务、文件和操作 / 当前对话内查找 | 应用 |
| `主键+1` 到 `主键+5` | 切到对应置顶任务 | 该位置须有任务 |
| `主键+U` | 打开/关闭任务菜单 | 已有任务 |
| `主键+J` | 配置本地环境 | 任务草稿 |
| `主键+L` / `主键+Shift+L` | 模型选择 / 切换加速 | 当前输入框；加速须模型支持 |
| `Enter` / `Shift+Enter` | 提交 / 换行 | 输入框；输入法组字或候选选择时先处理局部输入 |
| `主键+Enter` | 立即发送，或在空草稿时处理队首 | 输入框，不等于另建任务 |
| `Esc` | 停止当前回复 | 菜单、编辑或弹层先消费；不是回退文件 |

在 **设置 → 快捷键** 搜索动作、录入或清空绑定，再保存。被占用的全局键和无效组合需改用其他键；快捷键总开关、已清空项或局部焦点都会改变实际表现。Quick Chat 的 Option 组合见[另一套表](../../zpi-quick-chat/reference/shortcuts.md)。
