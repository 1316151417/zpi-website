# 少一次批准，不等于少一层本机权限

你发出「改这一行」之后，没有看到每个文件操作前都弹确认框。这让任务可以连续完成，但不意味着它只能看到聊天窗口里列出的文件。

**任务目录是起点，不是围栏。** 相对路径从 cwd 解释。绝对路径、Shell、运行的程序和网络连接仍受登录用户及操作系统的实际权限控制。工作树能隔离一份 Git 工作副本，但不是容器。分叉对话与切换模型更不会改变操作系统身份。

**能力与数据流是两件事。** 设置能告诉你模型可用哪些工具；停用提问不会禁用文件写入，停用网页搜索也不是阻断本机所有联网。工具读取的内容可能随上下文交给模型提供商。授权一个能执行命令的 Hook 或外部插件，也是在信任其代码；系统提示里写「只读」不能代替系统权限。

**所以审查发生在可见的地方。** 可以用练习目录、备份、最小必要工具和 Git 差异来核实结果，而不是从「模型说已完成」推断磁盘一定正确。官网浏览器里的临时桌面只是演示，这些真机边界不能从网页的受限行为反推。
