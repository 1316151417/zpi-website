# models | 模型与提供商
## chatgpt | 使用已有的 ChatGPT 订阅
在「设置 → 模型」选择 ChatGPT 的登录入口，用浏览器完成授权。回到 ZPI 查看连接状态和账号可用模型；若授权页要求复制回调地址，按界面提示把完整回调交还给 ZPI。

在任务输入栏选一个已启用的模型，发一句问候验证。订阅登录与 OpenAI API Key 是两种连接方式；不需要把 ChatGPT 密码粘进 ZPI，也不要把回调链接发给别人。
## api-key | 用 API Key 连接预置提供商
点「新增提供商」后选择真正签发这把密钥的服务商，不要只凭模型名相似就选 OpenAI。保留预置 API 格式，填密钥，启用至少一个模型并保存。

回到任务里发送一条最短消息来验证。用 DeepSeek 的完整首次路径见[连接第一个模型](../start/first-model.html)。401 类错误先查密钥与提供商是否配对。
## custom | 连接自定义服务：地址与 API 格式
新增时选 **自定义提供商**，分别填写显示名称、Base URL 和服务端实际支持的协议。支持 Chat Completions 不代表也支持 Responses；不要把完整请求路径重复拼进服务商要求的基础地址。

用服务商公布的一个准确模型 ID 做最小请求。404 先核对地址和协议，找不到模型再核对 ID；不要把内部服务地址或密钥写进项目文档。
## list | 获取并整理可选模型
在模型设置中获取服务商可用模型，选中提供商检查「模型列表」。启用你打算使用的模型，关闭不用的；需要时在列表里拖动调整顺序。

回到任务的模型选择器核对结果。服务商开关、单个模型开关和当前任务的模型选择是三件事，列表里存在并不等于当前任务已选中。
## add | 手工添加一个模型
服务可用但目录中没有模型时，点该提供商下的 **新增模型**。Model ID 必须与服务端公布的一致；显示名称只是你自己看到的标签。

核对上下文容量与最大输出，保存后启用，再用一条短消息验证。服务端拒绝未知 ID 时修改协议或显示名称都不能替代正确的 ID。
## switch | 在同一任务里切换模型
点输入框的模型名称（Mac 默认 Command+L），选择已经配置的另一个模型，再提交下一条消息。确认选择器显示新名称，不必为了换模型新建项目。

已经返回的文字不会重写；正在生成的一轮也不会中途移交。要比较两个模型的答案，先保留原回答，再决定是否分叉。
## reasoning | 调整当前模型的推理强度
在模型选择中选择该模型支持的思考级别。先对同一类小问题比较低级别与所需级别的用时和结果，不必对所有任务一律选最高。

若没有某个档位，先检查提供商和模型的推理能力定义。界面名称需要映射为服务端支持的参数，不能仅靠修改显示名增加模型能力。
## fast | 在支持的模型上打开加速
在输入区的模型菜单检查「加速」是否可用，切换后核对模型名旁的加速标记。Mac 默认快捷键是 Shift+Command+L。

不是每个服务商、模型和账号都支持相同请求选项。没有入口时先核对实际模型，不要误以为改变推理强度就一定等于启用了加速。
## edit | 编辑上下文窗口、输出上限和高级参数
在「设置 → 模型」选提供商，点某行模型的铅笔图标。**上下文窗口**是输入输出合计容量，**最大输出 Token**是单次输出上限。按服务商规格填写，而不是因为某次回答较短就任意增大。

高级配置可设输入类型、推理级别映射与请求参数。智能配置采用推荐值；手工修改参数会进入自定义配置。先只改一个值，保存并做小请求；取消则放弃本次编辑。

# usage | 上下文、性能与用量
## context | 查看当前模型还剩多少上下文
在「设置 → 界面设置 → 聊天」打开「显示上下文占用」，回任务点击输入栏的占用指示。看当前模型容量、用量和组成，区分对话文本与工具定义等开销。

分类占比与总体 token 数的统计依据不同，不要将比例当成逐项精确账单。容量吃紧时先移除无关材料，或[压缩旧对话](compact.html)。
## compact | 用 /compact 保留历史、缩短模型输入
在需要延续的长对话里输入 `/compact`，等待压缩完成。旧对话会形成摘要供后续请求使用，界面里的完整历史并不是因此被删除。

在下一条消息里重申决不能丢的细节，例如文件和验收条件。压缩不是启动空白任务、不是回退文件，也不能替代重要原文的保存。
## time | 查一次任务慢在模型还是工具
打开「显示模型性能与用量」，在输入框下点击任务统计。比较模型用时、工具用时、首 token 平均等待和输出速度；先判断主要是在等回复开始，还是工具本身在跑。

这些是整个任务已得到的统计，不是保证下一次响应有同样表现。未提供的指标与测得为零也不是同一件事。
## tokens | 查看输入、输出和缓存用量
打开任务的 Token 用量明细，区分未缓存输入、缓存读取或写入以及输出。两条外观看来相同的请求，历史长度和缓存命中可能完全不同。

用量记录适合比较任务开销；真实费用依服务商、账号和计价规则而定。不要把上下文容量当成本次实际用量。

# appearance | 界面、通知与快捷键
## theme | 设置界面主题和字号
打开「设置 → 界面设置 → 界面」。主题可跟随系统或固定浅色、深色。修改界面字号后看看任务列表和正文，不需要重启任务。

字号调整文字，不等比放大窗口图标。若只是 diff 字太小，应调整审查代码预览，而不是把整个工作区放大。
## diff | 单独调整审查代码的可读性
在界面设置的「审查代码预览」分别选择浅色、深色代码主题，设置代码字号。长行读不全可打开自动换行；需要讨论位置时启用行号。

用同一个改动文件对照调整前后的可读性。显示选项改变的是你看到的排版，不会重新格式化源文件或改变差异内容。
## controls | 选择输入区需要显示的控件
在「界面设置 → 聊天」分别切换发送按钮、模型性能与用量、上下文占用。若主要用键盘发送，可以只保留你真正查看的指标。

回到原任务检查输入区。隐藏一个按钮不等于停用整个能力：例如发送按钮不显示时仍可按 Enter 提交。
## notify | 设置任务通知和声音
在「设置 → 常规」打开任务通知。只想看提醒不想听声音时，保留通知开关、单独关闭通知声音。通知关闭时声音选项也不会独立发送提醒。

切到其他工作等待任务完成、失败或需要确认；没收到提醒时核对系统通知权限与任务通知插件，不要通过反复启动同一任务来测试。
## keys | 修改一个快捷键，解决绑定冲突
在「设置 → 快捷键」按操作名搜索，或按组合键搜索已有绑定。录入新组合，检查是否有保留键或冲突提示；不满意时恢复原绑定。

先在操作的有效范围测试：输入框快捷键和系统全局快捷键不是同一范围。记录前确认顶部快捷键总开关开启。
## summon | 用全局快捷键唤起或隐藏 ZPI
Mac 默认按 Control+Command+E 显示或隐藏 Desktop。先切到其他应用再试一次：窗口应出现，再按一次应隐藏，任务不会因为显隐而清空。

没有反应时到快捷键设置查「显示或隐藏窗口」，检查本机是否已换绑或被别的应用注册。不要和 Quick Chat 的 Option+Space 混用。

# data | 数据与故障排查
## history | 找到一项任务的会话记录
打开目标任务的任务菜单，使用「复制会话路径」。在本机核对它对应的会话，而不是把项目根目录误认作历史目录。

迁移或排错前先正常退出 ZPI，再备份完整的应用数据；只复制一个正在写的历史文件，无法保证索引和附件一致。不要在应用运行时手改历史。
## storage | 分清项目文件、附件与变更快照
项目文件是实际工作成果；会话记录保存对话；附件和变更快照帮助回看这一轮带入了什么、改了什么。归档管理里的永久删除针对任务数据，不替你删除项目源文件。

备份项目与备份聊天是两个目标。需要迁移时分别保留工作目录与应用数据；仅备份 Git 仓库不能保证找回聊天图片。
## no-model | 登录或保存 Key 后仍然没有模型
回到「设置 → 模型」，先确认选中的是刚配置的提供商，再检查提供商自己是否启用、是否有可用模型、单个模型是否开启。ChatGPT 路线还要确认浏览器授权真正返回了应用。

回任务点模型选择器选中一个，再发短消息。空列表与请求时报鉴权错误处理方法不同；前者先排模型配置，不要盲目重置密钥。
## locked | 密钥无法读取或解锁
看到凭据存储未解锁时，先取消编辑、解锁系统密钥存储，再按提示重启。恢复后检查连接状态，区分模型提供商的 key 和搜索服务独立使用的凭据。

不要把真实 key 发给助手排错，也不要为了让输入框看起来不空就覆盖已有凭据。确实泄露时应在服务商账户撤销并换发。
## restart | 重启后处理未完成的回复和排队消息
恢复任务后先看最后一轮的结束状态与文件差异。中断并不说明所有动作都没发生；已经记录的写入应先核对，再决定是否补做。

队列如果处于暂停，逐条检查、删除已不需要的要求，然后才恢复按顺序发送。不要复制整条旧任务重跑，否则可能重复修改。
## logs | 定位资源加载错误，准备可分享的日志
资源没有出现时，先展开界面的资源加载诊断，记录出错路径和原因。其他错误可在当前应用数据目录的 `agent/logs/error.log` 按发生时间查找；较早内容也可能在轮转文件中。

分享问题只附必要片段，先移除 key、授权回调、用户名、项目路径和私人内容。即使日志已有自动脱敏，也不要直接公开整份日志。

# lookup | 速查
## shortcuts | Mac 默认快捷键
这些是初始绑定，改过以后以「设置 → 快捷键」为准。

| 操作 | 快捷键 |
|---|---|
| 显隐窗口 / 新建任务 | Ctrl+Cmd+E / Cmd+N |
| 命令中心 / 当前对话查找 | Cmd+K / Cmd+F |
| 左侧栏 / 右侧栏 / 完整视图 | Cmd+[ / Cmd+] / Shift+Cmd+F |
| 聚焦输入 / 立即发送 / 停止 | Cmd+I / Cmd+Enter / Esc |
| 环境 / 模型 / 加速 | Cmd+J / Cmd+L / Shift+Cmd+L |
| 任务菜单 / 置顶任务 | Cmd+U / Cmd+1 至 Cmd+5 |

Shift+Enter 在消息中换行。其他支持平台的主修饰键通常为 Ctrl，但全局显隐单独配置。
## symbols | 输入框里的 @、#、$ 和 / 各做什么？
| 输入 | 找什么 | 例子 |
|---|---|---|
| `@` | 工作区文件，也可在候选中选择子智能体 | 指定同名文件中的一个 |
| `#` | 其他任务 | 引用此前讨论的任务 |
| `$` | 技能 | 带入项目发布清单 |
| `/` | 命令，也可浏览相关技能与子智能体候选 | `/compact` 摘要旧对话 |

选中候选后核对引用，再补上这一次的要求。输入符号本身不会写文件，也不会把某个候选的全部内容自动发出去。

## platform | 支持的平台、运行要求和版本
本册对照 Desktop 0.3.37。命令行入口要求 Node.js 24.x；教程主要以 Apple Silicon Mac 为例。Desktop 不支持 Windows，这个限制不等于 SDK 也不支持 Windows。

运行 `npx @zpi-dev/desktop --version` 查看实际包版本，`--help` 查看启动方式。线上包可能更新，版本差异先核对[本册适用版本](../../versions.html)，不要把网页演示当作本机模型或系统权限测试。
