# 查看正在运行的命令，并只停止该任务

右侧终端里没有输出，不表示 Agent 没在执行命令。先分清你要找的是哪一个执行者。

- **用户敲的命令**：在右侧新标签选「终端」。用 `pwd` 核对目录，输入 `printf 'ok\n'` 验证 PTY。切标签保留终端；关闭终端会销毁这个 PTY。不要用关闭聊天来代替停止该终端的作业。
- **Agent 发起的后台命令**：先确认新任务具有「后台命令」插件。要求将长期作业在后台运行。展开任务活动，找到描述和任务 ID，查看输出或日志。属于其他任务的 ID 不是本任务的操作凭证。
- **子智能体**：展开活动中的子任务，阅读该子任务的摘要或结果，而非把整个内部记录当终端输出。需要单独停止时对准相应子项，不要误停主回复。

验证：停止后该项离开运行态；完成通知或最后输出能辨认出是同一 ID。主回复结束、隐藏窗口或停止前台回复并不保证已转后台的命令停止。归档、删除或正常退出会清理相应作业；崩溃后历史中的旧 PID 不是可恢复进程。找不到后台选项时检查[工具启用条件](../reference/tools.md)，而不是反复轮询输出。
