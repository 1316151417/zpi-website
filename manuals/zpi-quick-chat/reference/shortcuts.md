# Quick Chat 快捷键与系统权限

这里查的是独立 Mac 浮窗。**Option 是 ⌥，Shift 是 ⇧；键位固定。** 五个全局键只有在进程运行并注册成功时才有效。

| 按键 | 动作 | 对数据与焦点的影响 |
| --- | --- | --- |
| Option+Space | 显示 / 隐藏 | 不新建、不停止；主动隐藏尝试把焦点还给原应用 |
| Option+Shift+Space | 新建并显示 | 清除当前临时对话、草稿和工具选择；不是「重新显示」 |
| Option+Shift+C | 带入前台应用的选中文字 | 用辅助功能执行一次复制；不把旧剪贴板当作新选区；需要手动发送 |
| Option+Shift+V | 带入现有剪贴板 | 不复制前台选区；优先取图片，否则纯文本；需要手动发送 |
| Option+Shift+A | 交互式区域截图 | 先隐藏浮窗；受 macOS 屏幕录制权限控制；取消不生成附件 |
| Enter / Shift+Enter（输入框） | 发送 / 换行 | 中文输入法选词时不把候选上屏当作发送 |
| Esc（窗口内） | 运行中停止；空闲时隐藏 | 图片、来源或错误提示可能先处理 Esc；不要连按代替判断状态 |
| Ctrl+C（启动终端） | 退出 CLI 和应用 | 释放全局快捷键，清空内存会话 |

没有选择文字时请用剪贴板路径，不需要为普通翻译打开本机 Shell。操作步骤见[带入与权限排查](../how-to/capture.md)。
